I'm a self-taught developer and aspiring **AI / ML Engineer**, interested in understanding, developing, and improving intelligent systems.

My work and learning revolve around machine learning, deep learning, generative AI, and building practical AI applications.

### Current Interests

- Machine Learning and model evaluation
- Deep Learning and neural networks
- Transformers, LLMs, and embeddings
- Retrieval-Augmented Generation (RAG)
- LLM fine-tuning with PEFT, LoRA, and QLoRA
- AI agents and agentic workflows
- Local, self-hosted, and offline AI systems

I value **understanding over abstraction**. I prefer learning the underlying mathematics and engineering principles before relying on high-level abstractions.
